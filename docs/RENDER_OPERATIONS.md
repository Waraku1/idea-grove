- Freeの休止・月間上限による停止を許容する。起動維持の定期アクセス、有料監視、有料DB、ディスク、自動スケール、有料ドメインを追加しない。外部DB/APIへの通信が多い場合もRenderがFreeサービスを停止することがある。
- Neon Freeのストレージ、CU-hours、転送量と復旧履歴を確認する。無料上限に達したら追加購入しない。プラン変更で停止を回避しない。長期の保存量は世界だけでなく履歴と索引を含む。

現行の公式上限は `RENDER_DEPLOYMENT.md` を参照する。実画面の対象契約・期間の値を優先し、確認日時と結果を記録する。

## 障害と保存停止

1. Render Environmentで `APP_READ_ONLY=true` として再デプロイする。更新・復元・消去は503になる。DBの読出しとホストの無料枠が残れば閲覧・JSON exportは継続する。
2. Renderのサービスログ・使用量・Build状態、Neonの使用量・接続、GitHub OAuth設定を確認する。本文、OAuth code/token、Cookie、接続URLをログやIssueに貼らない。
3. コード起因なら互換性のある直前の正常デプロイへ戻す。コードだけのロールバックでDBを巻き戻さない。無料プランの保持範囲を超える過去版は、同じGit SHAから手動で再ビルドする。
4. 保存・再読込・履歴・所有者分離を検証用アカウントで確認し、無料設定を再確認してから保存を再開する。時刻、SHA、原因、対処、影響を記録する。

サーバーは起動時に実DBの必要なテーブル・関数を確認する。`/healthz`は構成応答で、課金状態や継続的なDB可用性を証明しない。ポーリングの都度DBへ接続しないため、Neonの休止を妨げない。

## バックアップ

利用者はSettingsで現在の世界をJSON exportする。成長履歴は含まれない。旧Sitesからの移行も本人のJSONを本人のGitHubアカウントへ復元する。認証IDの一括置換や無断の全DB移行は行わない。

Neon Freeの復旧履歴は6時間。管理者はスキーマ変更・復旧の前に、`worlds`、`world_events`、`account_erasures`と関数定義を含む現在のSQLバックアップを取得する。全ユーザーの私的内容を含むため、暗号化した所有者管理の既存保管先で最大7日保管し、Git・公開サイト・会話には置かない。安全な保管先の設定と定期バックアップは未実施。自動バックアップが動いているとは扱わない。

## 消去済み内容を戻さない復旧

本人の消去は世界と履歴を原子的に削除し、固定ID・消去時刻だけを `account_erasures` に残す。保存処理と同じ所有者ロックを使い、削除前のrevisionによる保存を拒否する。消去記録は復旧時の再公開防止に使用する。

1. Renderサービスを一時停止してアプリの読出しも止める。`APP_READ_ONLY`だけでは古い内容の閲覧を止められない。過去のDBを公開中のサービスに直接復元しない。
2. **復旧直前の最新**消去記録と全DBを安全にバックアップする。最新の消去記録を確認できないときは、本番の過去復元を中止する。
3. 対象時刻・範囲・失われる更新を確認して、Neonで復旧する。全DBの巻戻しは他ユーザーの最近の更新も失うため最後の選択肢とする。本人1人の問題は本人のJSON復元を優先する。
4. 最新の消去記録を再適用する。同じownerの記録は最も新しい `erased_at` を残す。アプリ停止中、トランザクションで消去時刻以前の履歴を先に、世界を後に取り除く。消去後に本人が作り直した新しい世界は残す。

```sql
BEGIN;
DELETE FROM world_events WHERE EXISTS (
  SELECT 1 FROM account_erasures e
  WHERE e.owner_id = world_events.owner_id
    AND world_events.occurred_at <= e.erased_at
);
DELETE FROM worlds WHERE EXISTS (
  SELECT 1 FROM account_erasures e
  WHERE e.owner_id = worlds.owner_id
    AND worlds.updated_at <= e.erased_at
);
COMMIT;
```

5. スキーマ、revision、履歴再生、所有者分離、消去対象の不在を検証する。保存停止状態でサービスを再開して確認し、その後に保存を有効にする。利用者への連絡は所有者の明示した経路と指示に従う。本番復元や削除をテスト目的で行わない。
